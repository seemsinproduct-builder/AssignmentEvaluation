📖 Step-by-step setup guide
📖 Supabase Setup Guide

Step 1 — Create Supabase project

Go to supabase.com → New project → pick any name and region → wait ~2 min for provisioning.

Step 2 — Run the SQL schema

In your project → SQL Editor → paste and run 01_schema.sql, then 02_rls_policies.sql, then 03_trigger.sql (all files included in this package).

Step 3 — Get your credentials

Project → Settings → API → copy Project URL and anon public key.

Step 4 — Create your admin account

Project → Authentication → Users → Add user → enter email + password. Then in SQL Editor run:
INSERT INTO public.profiles (id, email, name, role)
VALUES ('<user-id-from-auth>', 'you@email.com', 'Your Name', 'admin');

Step 5 — Paste keys into EvalPro config

Come back here, paste the URL + anon key + your Anthropic API key → Save & Connect.
